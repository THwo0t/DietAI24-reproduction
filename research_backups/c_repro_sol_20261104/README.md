## 使用范围

这是源码和结果备份，不是完整数据运行包。源码保留原路径关系，但原图、标签、目录、索引、C布局及缓存等资产仍只在原本地研究档案中。
不能仅凭此目录直接完整重跑。原 `run.py` 会要求这些资产及原冻结绑定；原 `verify_completed.py` 还会读取本地凭据做泄漏检查。
`comparison.py` 和 `task_usage.py` 分别还依赖历史比较产物和原始用量账本；备份已保存它们的最终输出，不能在缺少原档案时声称重新核验了历史全过程。
无需API即可核对本备份文件及预测结构：

```sh
python3 verify_backup.py
```

本次整理没有调用付费API、没有重跑历史实验，也没有修改本地冻结源码或结果。
