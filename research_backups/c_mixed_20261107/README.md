# 混合 C 开发实验公开备份

本包保存 2026 年 11 月 5 日完成的 `c_stage_split_20261105` 源码与结果，以及 11 月 7 日的 N5 无回退离线复算。

- Gemini 3.8 Flash 负责图像识别、选择食品码与 Nutrition5k（N5）估重。GPT-6.1 Sol 负责纯文本查询改写和 ASA24 估重。本次历史实验从全视觉 Gemini 版原样复用了 N5 预测和 ASA24 识别选码，只重新做了 ASA24 份量阶段。
- 检索沿用原版多查询 FNDDS（美国膳食调查食品与营养数据库）流程。N5 每个食物用 1–3 个已选食品码的平均营养密度和该食物重量计算营养。ASA24 条件分支使用命中的单个参考食品码及其合法份量选项。
- 原文件中的 843 是开发评分记录数。按冻结开发清单中的原图 SHA-256 去重，共 663 张原图，N5 为 314 条、314 张，ASA24 为 529 条、349 张。历史 ASA24 条件结果统计命中参考码的 176 条记录，另有全部 529 条的整体结果。独立验收集保持封存。

## 历史结果与当前口径

[历史报告](results/RESULTS_中文.md)和机器可读结果保留当时的原始及按组跨折修正两套数值。修正系数现已弃用。旧 N5 的 314 条原始分数含 1 条失败后的开发标签中位数回退。

[无回退复算](results/n5_313_no_fallback/结果_中文.md)用已有原始预测评分，314 条尝试中有 313 条有效，1 条失败单列。重量、热量、脂肪、碳水和蛋白质的平均绝对误差分别为 **51.249201 g、82.012174 kcal、6.088010 g、7.510611 g、5.968640 g**。各项 per-unit 用 313 条真实值的对应均值作分母。复算口径的变化未涉及重新推理。

- `source/` 按项目原路径保存 28 份历史冻结 Python 文件和 2 份依赖清单。依赖清单与前一公开备份一致，未列入历史运行冻结。冻结源码保留字节原貌，其中一份已公开的历史依赖保留本机路径常量。
