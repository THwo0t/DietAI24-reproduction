# P-C0: path inventory before actual exposure projection

This first bounded P-C action inventories path types and sizes in the canonical
repository, plus the presence of four fixed legacy manifests. It opens no
research-file bodies, images, labels, request caches or credentials. It neither
calls the N5 identity reader nor captures the ASA archive. Excluded directories,
links, special files and absent legacy manifests remain explicit limitations.
Actual inputs, failed attempts and interrupted runs must subsequently be
reconciled before source association, numerical eligibility or sampling.

The production command accepts no arguments:

```sh
unshare -Urn .venv/bin/python -B optimization_sol_20261102/mae_v2/round11/source_census.py
```

It authenticates the registered DESIGN, independent retrospective dispositions,
completed diagnostic recovery and remote-verified failed-O backup by fixed
hashes. It also checks the previously recorded O completion/verification/score
anchors and recovery source pins. This consumes the prior recovery; it does not
repeat the O proof replay, diagnostics, scoring or inference. It does not claim
fresh integrity of every underlying O store body.

The sole new output is private, exclusively created (0600 inside 0700):
`round11/preparation/inventory/source_census.json`. No overwrite/resume switch or
root/pin override exists. A failure or partial exclusive write is preserved for
diagnosis and does not grant a retry that overwrites evidence. Stdout exposes
only aggregate counts and a fingerprint; failures expose only the exception
type. The census repeats path metadata capture and control hashing before the
write. It certifies neither source contents nor complete actual API exposure.

This is trusted bounded Python running in a loopback-only network namespace,
not a general sandbox for arbitrary extensions. No dynamic plugins, provider,
credential loader or subprocess implementation is imported. Directory traversal
uses no-follow directory descriptors, including the per-child inode binding;
symlink entries are retained without following them.

Offline evidence covers protected-body non-opening, same-size/restored-mtime
control mutation, symlink/FIFO refusal, nontraversal of linked trees, stale O
anchors, changes between captures, inventory bounds, strict JSON and CLI/network
refusal. All fixtures are synthetic. P-C0 requires one independent review and
root confirmation of its P1/P2 fixes before its first production invocation.
This review cannot approve the still-pending actual source/exposure projection,
full graph/cohort preparation, download or paid-run integration.
