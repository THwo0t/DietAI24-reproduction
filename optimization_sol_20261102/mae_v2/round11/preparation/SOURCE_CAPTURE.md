# P-C1: mechanical source identity capture

This bounded stage follows the completed path census. It captures registered
identity sources without claiming that latest actual API exposure or full
source associations have been closed. It cannot evaluate candidate eligibility,
select/download samples, freeze cohorts or invoke a model.

Production has no arguments, path/pin overrides or resume/overwrite flag:

```sh
unshare -Urn .venv/bin/python -B optimization_sol_20261102/mae_v2/round11/source_capture.py
```

Prerequisites are fixed completed-O/recovery/retrospective/backup control pins
and the first private path census hash. Prior O verification, diagnostics,
inference and scoring are not repeated. No existing cohort is modified.

Twelve implementation sources are hash-bound before/after capture, alongside
Python, Pillow and openpyxl runtime versions and both exact-RGB rule names.
These are execution provenance, not a new formal scientific cohort freeze.

The N5 adapter authenticates exactly the15 previously registered identity,
snapshot, proposal, training-audit and raw-metadata sources. It rebuilds the
supplied raw-scan/recipe/byte/RGB identity graph and role exclusions. Ingredient
masses may be interpreted mechanically for scan linkage; no five-target dish
value, including unprotected candidate targets, is converted or used. Available
metadata remains captured bytes only. No eligibility function is called and
the provisional metadata-only allowed-ID set is not exported.

The original authenticated N5 snapshot supplies the hash of the fixed original
cohort protocol. That protocol authenticates exactly five named ASA sources;
arbitrary paths in either inventory are not followed. Only the workbook and
source ZIP bodies are opened here. FNDDS/top1000/weight table pins are recorded
as registrations, without claiming those three bodies were freshly verified.
Workbook projection retains all identity edges and image names, including
SIZE, modified-code, uncoded and inventory-only rows. Deferred portion values
are neither interpreted nor saved. The complete local source ZIP is hashed
before/after capture and through the fresh fixed path; every PNG, including
unassociated members, receives the registered exact byte/RGB fingerprint.
No files are extracted and no image is visually inspected.

Mechanical source-archive fingerprinting may include images corresponding to
validation identities. This is the permitted blind association adapter, not
validation image analysis, prediction or method selection. Separate sealed
validation image/label files are never opened. No current dish target, legal
portion value, raw table, oracle per-item weight or deferred workbook field is
saved in the new artifact or given to any predictor.

Output is exclusively created0600 under0700:
`round11/preparation/capture/source_capture.json`. It contains only identity
projections, fingerprints and source bindings. Stdout contains ID-free counts
and a hash, with explicit false source/exposure-completeness and action grants.
Missing/changed sources, unknown source aliases, decoder faults, graph bridges
or output failures refuse the capture; there is no automatic substitution,
validation repair or reclassification. Partial output remains preserved.

The existing N5 and ZIP readers now acquire every ancestor through held
no-follow descriptors before opening a body; synthetic parent-substitution
regressions cover both. Source components and the CLI use synthetic fixtures
only before this stage's single independent review. After P1/P2 fixes, root
confirms offline and may perform the first mechanical capture. This is an
engineering audit action, not MAE evidence or approval of the full P-C/P-D run.

Next isolation work can use a conservative union of potential historical inputs
to quarantine candidate components. Such a superset does not require exact
attribution of every support that reached an API, but its caller/history/source
coverage must itself be closed. Planned/proven/unresolved exposure accounting
remains separate; unexplained sources cannot be declared safe by this capture.
