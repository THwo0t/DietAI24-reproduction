vision method. ASA generic V3 stays strictly PNG/JPEG. Model-image preprocessing
and its profile are unchanged. GIF never receives an ASA fingerprint or counts
as ASA compatible.

The pure path predicate accepts only direct `.gif` children of those four exact
directories under `.tools/python/cpython-3.10.13-linux-x86_64-gnu/lib/` in the
five fixed roots. Broad dependency classification alone is insufficient. The
private loader derives the allowance from both this predicate and authenticated
dependency classification; there is no CLI or public opt-in. Other GIF content
fails closed. The private decoder retains existing byte/pixel bounds, verify,
full RGB load and single-frame checks. It uses the existing N5 size-tuple/NUL/RGB
hash algorithm and retains byte digests, every path and all alias bridges.
The N5 overlay independently requires exact dependency path/classification proof
for GIF and refuses ASA compatibility for GIF. Unassigned rows remain potential
inputs requiring later blind collision checks.

Synthetic tests exercise all five roots/four directories, forbidden unrelated
`.tools` and research paths, default GIF refusal, bounds, animation, all path
retention, byte/RGB alias behavior, invalid digests and target-field poison.
Existing PNG/JPEG tests remain in the same suite. No real census/image/label
body, network provider, or paid API is used by this implementation validation.
