# ASA adapter retained for the paired mechanism comparison

This prospectively specifies the permitted ASA adapter before Q/D inference.
It supplements DESIGN.md and does not grant a paid run or independent success.

All four profiles execute the same blind identity/retrieval definition and
their declared whole-image quantity/density stages on both datasets. For ASA,
these whole-image predictions are the separately reported all-record E2E task.
Q changes its whole-image mass estimate; D changes density choice within its
frozen alternative set. Final code-set membership remains unchanged. Report
the original primary and the primary after D separately, including first-code
recognition; conditional Exact membership uses the unchanged complete code set.

The primary ASA conditional-option task retains O's already effective isolated
adapter for all four profiles: after the complete coding seal, supply only the
matching true code and its entire legal catalogue, estimate continuous mass,
then map to the nearest legal option. One physical conditional request/result
is shared across profiles, with exact provenance. This conditional task differs
from blind whole-image E2E; do not feed its true code, legal catalogue or output
back into any blind identity, Q or D request.

Thus Q/D interventions are compared on blind E2E, while conditional ASA MAE is
a retention control with a shared frozen adapter. D cannot replace the true
code's nutrient density in conditional scoring. Q's blind mass must not silently
replace the adapter's conditional estimate. This preserves a coherent common
method with an explicitly permitted task adapter, rather than selecting an
answer or a historical score separately for each target. New eligible ASA
portions still receive predictions under that adapter; old calibrated scores
are never imported. Raw prediction reuse requires exact payload provenance.

All Exact rows enter option scoring. Exhausted conditional structural failure
uses that code's median-weight legal option. Fit any existing one-multiplier
ASA calibration only on the new training folds before legal mapping; do not
scale a final option's grams or use current reference size/weight/nutrients.
The common identity set, Exact counts/groups, three sizes, original18% target,
secondary recognition guard, all-record E2E and failure rates remain explicit.
The complete runner and isolated code-only projection still require their
first integrated review and freeze before use.
