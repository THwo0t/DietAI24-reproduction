What changed when the model changed

Offline presentation · archived measurements · zero API calls

GPT-4 Turbo was unavailable during the reproduction. We tested GPT-4o, then added Sol with its supported settings. Sol reduced weight underestimation on shared Nutrition5k dishes; nutrient accuracy and exact identification did not consistently improve.

Both configurations used the same samples, prompts, parsing and evaluation. Sol required temperature 1 and a larger description token budget. The model and these settings cannot be separated. Each formal configuration was run once.

Evidence and interpretation

ASA24 MAE is conditional on Exact identification. Nutrition5k MAE includes only complete dishes. Shared subsets reduce differences in coverage but remain selected subsets. A smaller weight error does not establish better nutrient estimation or attribute the full reproduction gap to model capability.
